# Student Portal v1

A simple Flask web application for managing students.

## Features

- Homepage
- Register students
- View all students
- Student detail page
- In-memory storage
- Flask Blueprints
- Jinja2 templates
- Unit tests

## Installation

```bash
python -m venv .venv
source .venv/bin/activate

pip install -r ../requirements.txt
```

## Run

```bash
cd task13
python run.py
```

## Tests

```bash
pytest
```
